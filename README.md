# Vikunja/Playwright End to End Tests

End-to-End Playwright suite for Vikunja, running in a disposable Docker Compose envirnonment.

***This is an unofficial test suite independent of the official Vikunja Project***

## Quick Start
**Prerequisites:** Docker with Compose

## Status
- Actively being developed.

## Goal
One command (`docker compose up`) starts Vikunja, runs a health check, runs the tests once Vikunja is ready and exits with a pass/fail code. Saves test results on host machine.
